# Ties 0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add local sources (Contacts extras, Messages, WhatsApp, Mail) as search seeds, verification evidence and relationship data; make research several times faster with a search pool and engine failover; add six unobtrusive AI features; ship as 0.2.0.

**Architecture:** New `Signals` module in TiesCore: pure `SignalRules` (honorifics, aliases, signatures, links) + one collector per source reading a read-only temporary copy of the source store, orchestrated by a `SignalCollector` actor that streams `ScanProgress`. Signals feed `ProbeInput`, `SearchQueryBuilder` and `CandidateScorer`. A `WebKitSearchPool` fans queries over N engine-parameterised web views with failover. `AIProvider` gains a generic schema-constrained `complete` used by five small AI services. The app adds a Sources wizard step, Known-as/Relationship/Reconnect/Smart-list UI, Draft, judge chips and the privacy switch.

**Tech Stack:** Swift 6, SwiftUI, GRDB 7 (FTS5), SwiftSoup, PhoneNumberKit, NaturalLanguage, WebKit, Foundation `NSMetadataQuery`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-16-ties-0.2-design.md` (the 0.1 spec `2026-09-16-ties-design.md` still binds everything not changed there).

## Global Constraints

- macOS 15 minimum; Swift 6 strict concurrency; `swift build` and `make build` with zero warnings.
- Dependencies: exactly GRDB.swift, SwiftSoup, PhoneNumberKit. No new packages.
- Tests: Swift Testing (`@Test`, `#expect`) only; fixtures created by the tests, never real user data.
- Sources are read from a temporary copy, opened read-only, never written; per-person caps: 500 messages per handle (Messages, WhatsApp), 50 messages per address (Mail).
- Local signals feed search seeds by design; the cloud-AI switch decides what a cloud provider sees (aliases, titles, companies, honorifics, and the user's own last 20 messages to a person when a draft is asked for). Never a message someone sent the user, a subject line, or the address book. On-device Apple Intelligence may see everything.
- UI: native SwiftUI, icons and logos not labels, no subtitles that repeat the title, `.snappy`, system materials; every new element uses the SF Symbol named in spec §8.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- The owner's real address book is in the app's database on this Mac: never run a scan, collection or extraction against it during verification; `make run` only to confirm launch.

```swift
public enum Honorifics {
    public static let english: [String: [String]]   // "dr": ["doctor","physician","dentist","phd","md"], "eng": ["engineer"], "prof": ["professor"], "sheikh": [], "capt": ["captain","pilot"], "adv": ["lawyer","attorney","advocate"], "arch": ["architect"]
    public static let arabic: [String: String]      // "دكتور": "dr", "دكتورة": "dr", "د.": "dr", "مهندس": "eng", "مهندسة": "eng", "م.": "eng", "أستاذ": "prof", "استاذ": "prof", "أ.": "prof", "شيخ": "sheikh", "كابتن": "capt", "محامي": "adv"
    public static func canonical(_ token: String) -> String?      // "Dr." / "DR" / "دكتور" → "dr"; nil if not an honorific
    public static func professions(for canonical: String) -> [String]
}
public struct SignatureBlock: Sendable, Hashable { public var name: String?; public var titles: [String]; public var companies: [String]; public var phones: [String]; public var links: [String]; public var location: String? }
public enum SignalRules {
    public static func honorifics(in text: String, names: [String]) -> [String]        // canonical honorifics found immediately before any name token
    public static func aliases(in text: String, names: [String], minOccurrences: Int = 3) -> [String]  // capitalised 1–3 word names near the person's handle mention, excluding the known names
    public static func signature(in body: String, senderName: String?) -> SignatureBlock?
    public static func links(in text: String) -> [String]                               // canonical URLs for linkedin.com/in, x.com, twitter.com, github.com, and any https URL with a path ≤ 2 segments
}
```
Signature rules (spec §4.2): take the last ≤ 8 non-empty lines after the last marker line matching `^(-- ?|regards|best|thanks|kind regards|cheers|sincerely|تحياتي|مع التحية)` (case-insensitive, optional trailing punctuation) or after the last line equal to the sender's name; reject if the block has > 3 URLs or contains `>` quote markers or `wrote:`; a title line matches `^(?<title>[^|,@]{3,60}?)\s*(\||,|at|@|-|–)\s*(?<company>[^|,]{2,60})$` or a single line that contains a profession word from `Honorifics.professions`; phones via PhoneNumberKit with region "SA" fallback "US"; location = a line matching `^[A-Z][a-z]+(,\s*[A-Z][a-z ]+)?$` that is not the name or company.
